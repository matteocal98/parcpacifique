Suivre ce coût machine par machine

KALEA le recalcule à partir de vos interventions et dépenses enregistrées. Le suivi du coût (TCO) fait partie de l'offre Business, à partir de 39 €/mois.

Voir les offres

Comment le calcul est fait

(prix d'achat − revente estimée + dépenses) ÷ (compteur aujourd'hui − compteur à l'achat)

La perte de valeur est ce que vous avez payé, moins ce que vous pourriez en tirer aujourd'hui. On y ajoute vos dépenses depuis l'achat, puis on divise par les heures ou les kilomètres faits pendant que la machine est à vous.

Machine achetée d'occasion

Seul votre usage compte. Une machine achetée à 3 000 h et affichant 5 400 h a fait 2 400 h chez vous : diviser par 5 400 h donnerait un coût trop bas.

Bien comparer deux coûts

Pour comparer deux machines, ou un coût avec un tarif de location, comptez les mêmes dépenses des deux côtés : carburant, assurance, transport, conducteur.

KALEA calcule ce coût machine par machine à partir de vos interventions : voir le logiciel GMAO.

Questions fréquentes

Mes montants sont-ils envoyés ou enregistrés ?

Non. Le calcul se fait dans votre navigateur et rien de ce que vous saisissez n'est transmis. Seule la visite de la page est comptée, sans cookie.

Que mettre dans la revente estimée ?

Le prix que vous pensez pouvoir obtenir aujourd'hui. C'est une estimation : le résultat change avec elle. Laissée vide, tout le prix d'achat est compté.

Faut-il compter le carburant ?

Comme vous voulez, à condition de faire pareil pour toutes les machines que vous comparez. Le champ est facultatif.
