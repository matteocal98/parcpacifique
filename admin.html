    Ce qui n'est pas mesuré ici

    Le trafic sortant (Egress, 5 Go/mois) et les journaux ne sont pas lisibles depuis la base : ils se lisent dans le tableau de bord Supabase (Organisation → Usage). C'est l'Egress qui atteindrait son plafond le plus vite avec beaucoup de clients et de photos de machines.

    Le nombre d'utilisateurs actifs est une estimation (connexions sur 30 jours) : Supabase compte légèrement différemment.

    Supprimer cette société

    • Tout est supprimé définitivement : machines, plans, entretiens, pièces, stock, télémétrie, tickets, fichiers et comptes de connexion de tous les membres.
    • L'abonnement Stripe éventuel est résilié avant. S'il ne peut pas l'être, rien n'est supprimé.
    • Une société qui contient un compte du personnel KALEA est refusée.
    • L'opération est inscrite dans le journal d'audit.
